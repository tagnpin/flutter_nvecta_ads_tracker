# Changelog

### Version 1.0.0 _(November 09, 2026)_

---

Introducing flutter plugin for integrating NVECTAAdTrackingSDK and managing ATT and IDFA tracking with NVECTA or notifyvisitors package.

- Initial stable release.
- Added integration with NVECTAAdTrackingSDK.
- Added App Tracking Transparency authorization support.
- Added IDFA tracking support.
- Added Swift Package Manager support.
- Added CocoaPods support.
- Added support for iOS 14 and later.
